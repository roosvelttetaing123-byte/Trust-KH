# Source register
Reviewed 9 September 2026. Sources establish public context, not product performance or authorization. Recheck dates, prices, terms and eligibility before relying on them. Summaries are deliberately narrow.

- **S1 — MPTC, CDA 2026.** https://mptc.gov.kh/cda26/ — category descriptions, eligibility wording, document guidance and dates. No numerical scoring weights were established from the public page reviewed.
- **S2 — Kapea Scams developer listing.** https://play.google.com/store/apps/details?id=com.accd.kapeascams — developer identifies ACCD; advertised lookup/reporting/call protection. Advertised features, not an independent test.
- **S3 — Singapore ScamShield.** https://www.scamshield.gov.sg/check-for-scams/how-to-check-for-scams-on-scamshield-app/ — official screenshot/message checking workflow. Regional comparator, not proof of local performance.
- **S4 — NBC Bakong/KHQR.** https://bakong.nbc.gov.kh/en/ — EMV-based KHQR and published integration resources. This does not grant account ownership verification access.
- **S5 — Cambodia National Police complaint portal.** https://hotline.police.gov.kh/ — separate official complaint channel. No submission API is assumed.
- **S6 — Google Safe Browsing.** https://developers.google.com/safe-browsing — non-commercial use restriction; commercial architecture requires appropriate terms.
- **S7 — VirusTotal API terms.** https://docs.virustotal.com/reference/public-vs-premium-api — public API commercial-use restrictions. An API key is not a resale license.
- **S8 — OWASP SSRF Prevention.** https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html — relevant to any future URL retrieval; current prototype does not fetch submitted URLs.
- **S9 — Telegram Bots FAQ.** https://core.telegram.org/bots/faq — opt-in bot message visibility and group privacy constraints; not arbitrary access to chats.
- **S10 — MPTC on VERIFY.** https://mptc.gov.kh/en/2024/02/cambodias-verify-gov-kh-document-verification-platform-wins-gold-in-asean-digital-awards-2024/ — documentary verification and recognition context. Trust.kh is not VERIFY or an endorsed extension.
- **S11 — Google Web Risk pricing.** https://cloud.google.com/security/products/web-risk — separate Lookup and hash/update pricing. Confirm exact API, licensing and current rates before budget approval.
- **S12 — FastAPI container documentation.** https://fastapi.tiangolo.com/deployment/docker/ — container deployment guidance; not evidence of production readiness.
