# Security and responsible use

This repository is a local defensive prototype. It does not authorize scanning, probing, exploitation, account investigation or collection of private messages. Use synthetic inputs until release gates and data permissions are complete.

Do not post real evidence, personal data, credentials or exploitable sensitive deployment details in public issues. Contact the repository owner through an appropriately private channel for sensitive reports. No dedicated disclosure mailbox or response SLA is claimed.

The current app uses role-specific development keys, local SQLite and in-process limits. It is not ready for network-facing deployment. See docs/RELEASE_GATES.md. No public instance has been established by this repository.
