# Security and data handling

Local prototype only. Do not submit real citizen reports, credentials, identifying documents, bank data or private evidence through public issues. Do not test systems you do not control.

For a security concern, contact the repository owner through an already established private channel. If a private reporting route is not configured, request one without publishing exploit details or sensitive evidence. An official security contact and response policy are required before public operation.

No broad bug-bounty authorization, safe-harbor promise, production SLA or government authority is implied. Review `docs/RELEASE_GATES.md` before changing deployment scope.
