DESIGN BOUNDARY

No arbitrary browsing.

The app does not visit submitted URLs. External reputation and extraction require an approved provider, privacy decision, cost cap and explicit availability states.

Publication is a separate boundary.

Production Pulse should read approved fixed-period snapshots, not an unrestricted case database. Current small-cell suppression is not an anonymity guarantee.
